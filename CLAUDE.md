# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Сборка и проверки

```bash
npm install              # один раз: ставит jsdom, на нём написаны все проверки
python3 build.py         # пересобрать index.html из шаблона и данных
npm test                 # все четыре набора подряд

node tests/basic.js      # запуск, отметки, сохранение, переключение дня
node tests/edge.js       # битые данные, отказ хранилища, гонки, доступность
node tests/progress.js   # автопереход на следующий день
node tests/audio.js      # фоновый сигнал: старт в касании, работа в фоне
```

**Коду выхода верить нельзя:** `basic`, `edge` и `progress` завершаются нулём даже при провалах, ненулевой код возвращает только `audio`. Результат читается глазами по последней строке: «провалов: N» у `basic`, `edge`, `audio` и «ошибок: N» у `progress`.

## Устройство сборки

`index.html` — сборочный артефакт, **править его руками нельзя**: любая правка перетирается следующим `python3 build.py`. Интерфейс, стили и скрипт живут в `template.html`, содержание — в `data/*.py`.

`build.py` читает `data/program.py` через `ast.literal_eval`, исполняет `data/terms.py` через `exec` и подставляет три плейсхолдера в `template.html`:

- `__DAYS__` — программа по дням из `DAYS`
- `__GLOSS__` — глоссарий из `TERMS`, ключ картинки разворачивается в путь `assets/gym/<ключ>.jpg`, а `ref:<ключ>` — в ссылку на другой термин
- `__IMGKEYS__` — список ключей иллюстраций, собранный из имён файлов в `assets/exercises/`

Тесты читают собранный `index.html`, а не шаблон. Поэтому правка `template.html` или `data/*.py` без пересборки в тестах не видна.

### Формат упражнения в `data/program.py`

Ключи короткие: `n` — название, `l` — строка подходов («4 × 8–12»), `c` — подсказка, `img` — ключ иллюстрации из `assets/exercises/` без суффикса кадра (`_0` старт, `_1` финиш), `rest` — отдых в секундах, `t` — длительность для кардио, `hold` — удержание, `iv` — интервалы `[работа, спокойно, круги]`, `w: 1` — разминочное упражнение.

Упражнение считается силовым (с отметками подходов и полем веса), если у него нет ни `w`, ни `t`, ни `iv` — эта проверка повторяется и в коде, и в тестах.

Внимание на совпадение имён: `w` у упражнения — это признак разминки, а `w` в записи журнала весов — сам вес.

### Формат термина в `data/terms.py`

Кортеж `(ключ, заголовок, объяснение, ключ картинки или None, [шаблоны])`. Шаблоны — регулярные выражения для подсветки термина прямо в тексте карточек; `\w` в них заменяется на класс, включающий кириллицу.

## Правила, выведенные опытом

1. **После любой правки прогонять все четыре набора тестов.** Они уже ловили обращение к переменной до инициализации, падение всего приложения от одной битой записи в журнале и рассинхрон таймера с отметкой подхода.
2. **Тренажёры опознаются только по наклейке на самой машине,** не по внешнему виду — так уже дважды ошиблись. Ориентир — надпись на наклейке (LEG PRESS, LAT MACHINE, ARM CURL, KNEELING EASY CHIN DIP, PECTORAL / REVERSE FLY), а не номер машины. Нет наклейки на фото — просить фото наклейки, не гадать.
3. **Картинки не встраивать в `index.html`.** Когда они лежали в base64, файл весил 2,1 МБ и предпросмотр обрезал его на середине скрипта. Сейчас 89 КБ.
4. **Репозиторий публичный:** на фотографиях зала не должно быть узнаваемых посторонних людей.
5. **Числа и факты программы проверять по авторитетным источникам** перед внесением.

## Ограничения платформы, влияющие на код

Приложение живёт на айфоне как иконка на домашнем экране, оболочка — WebKit. Отсюда неочевидные решения в `template.html`:

- **Звук таймера в фоне.** JavaScript при уходе в другое приложение замирает, воспроизведение звука — нет. Поэтому на старте отсчёта генерируется WAV «тишина нужной длины плюс сигналы» и играет до конца. Запускать дорожку обязательно внутри касания и не останавливать при уходе из вкладки: начать воспроизведение при уже скрытой странице WebKit не даёт, а `play()` отклоняется молча. Тип аудиосессии — `playback`, при `transient` в фоне звука нет. Пока дорожка играет, `beep()` не дублирует её звук.
- **Цена фонового звука.** Играющая дорожка занимает аудиосессию и ставит музыку в наушниках на паузу на всё время отдыха. Звучать в фоне и микшироваться с чужой музыкой на iOS одновременно нельзя: `playback` не микшируется, а `ambient` и `transient` не продолжаются в фоне. Поэтому дорожка сидит под переключателем `cfg().bg` и **по умолчанию выключена** — при выключенной настройке `scheduleTrack()` выходит сразу и звук на экране даёт прежний `beep()`. Не включать её по умолчанию: тишина вместо музыки на каждом отдыхе — худший вариант, чем отсутствие сигнала в фоне.
- **Второй путь к сигналу в фоне** — `fireExternal()`: отдать отсчёт системному таймеру через «Быстрые команды» (`cfg().ext`, тоже выключено по умолчанию). Системный таймер звонит при заблокированном экране и музыку только приглушает.
- **Уведомления** вне вкладки веб-странице на iOS недоступны — отсюда и трюк с дорожкой. Есть выключенная по умолчанию настройка: отдавать отсчёт системному таймеру через «Быстрые команды».
- **Браузерная память** недоступна страницам со схемы `file:` — проверять сохранение весов можно только по адресу `https://`.
