# Программа тренировок — Icon Fitness, Модиин

Одностраничное приложение: программа на три дня, таймер, журнал весов, глоссарий с фотографиями зала.

## Структура

```
index.html          собранный файл — его и публикуем
template.html       шаблон: разметка, стили, скрипт
build.py            сборка index.html из шаблона и данных
data/program.py     упражнения по дням: подходы, подсказки, отдых
data/terms.py       глоссарий: термины, описания, шаблоны поиска в тексте
assets/exercises/   иллюстрации движений, по два кадра на упражнение
assets/gym/         фотографии тренажёров зала
tests/              проверки на jsdom
```

## Работа

```bash
npm install                      # один раз: ставит jsdom для тестов
python3 build.py                 # пересобрать index.html
npm test                         # все четыре набора подряд

node tests/basic.js              # запуск, отметки, сохранение, переключение дня
node tests/edge.js               # повреждённые данные, отказ хранилища, гонки, доступность
node tests/progress.js           # автопереход на следующий день
node tests/audio.js              # фоновый сигнал: старт в касании, работа при уходе в другое приложение
```

После правки `data/program.py` или `data/terms.py` обязательно `python3 build.py`, иначе изменения не попадут в `index.html`.

## Публикация

GitHub Pages, ветка `main`, папка `/ (root)`. Публиковать нужно `index.html` **вместе с папкой `assets`** — картинки теперь отдельными файлами.

## Ограничения, выясненные опытом

- В предпросмотре файлов внутри чата Claude нет ни сети, ни постоянного хранилища. Веса сохраняются только на опубликованном сайте.
- Файл тяжелее ~1,5 МБ предпросмотр обрезает, и скрипт не выполняется. После разделения на файлы `index.html` весит 89 КБ.
- Safari не даёт браузерную память страницам, открытым с диска (схема `file:`). Нужен адрес `https://`.
- Таймер в фоне звучит за счёт сгенерированной аудиодорожки: JavaScript в фоне замирает, воспроизведение звука — нет.
