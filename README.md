# Программа тренировок — Icon Fitness, Модиин

Одностраничное приложение: программа на три дня, таймер отдыха, журнал весов, словарь с фотографиями тренажёров зала. Открывается с айфона как иконка на экране «Домой».

## Структура

```
index.html          собранный файл — его и публикуем, руками не править
template.html       шаблон: разметка, стили, скрипт
build.py            сборка index.html из шаблона и данных
data/program.py     упражнения по дням: подходы, подсказки, отдых
data/terms.py       словарь: термины, описания, шаблоны поиска в тексте
assets/exercises/   иллюстрации движений, по два кадра на упражнение
assets/gym/         снимки тренажёров для словаря
tests/              проверки на jsdom
docs/research/      замеры звука на iOS и откуда взяты фото тренажёров
```

## Работа

```bash
npm install          # один раз: ставит jsdom для тестов
python3 build.py     # пересобрать index.html после любой правки шаблона или данных
npm test             # все четыре набора проверок подряд
```

## Публикация

GitHub Pages, ветка `main`, папка `/ (root)`. Публикуется `index.html` вместе с папкой `assets`.

Сохранение весов работает только на опубликованном сайте: страница, открытая с диска или в предпросмотре чата, браузерной памяти не получает.
